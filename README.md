# FM-FL Privacy Artifacts

This repository contains the artifacts for our paper on privacy in federated learning and foundation model systems.

## Contents

- `data/survey_corpus/`  
  Structured survey dataset, including CSV files

- `case_studies/`  
  Code, configurations, and outputs for the case study experiments used in the paper.

- `figures/paper_figures/`  
  Figures used in the manuscript.

- `docs/`  
  Additional notes about the artifact and repository organization.

## Survey Corpus

The survey dataset includes structured metadata for the references used in the paper.  
The `ref_no` field matches the citation numbering in the manuscript.

Files:
- `survey_papers_160.csv`

## Case Studies

Case study is stored in its own subfolder and may contain:
- source code
- configuration files
- scripts
- generated results such as figures and tables

## Notes

This repository is intended to support transparency and reproducibility of the paper.
